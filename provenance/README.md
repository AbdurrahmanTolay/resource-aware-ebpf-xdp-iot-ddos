# Provenance

This directory contains templates for documenting new replication runs.

- `RUN_MANIFEST_TEMPLATE.csv` is the recommended run-level metadata schema.
- `EXAMPLE_PAIRED_RUNS.csv` illustrates a matched mitigated/unmitigated layout only; it is not historical research data.

For a new campaign, record at least the code commit, timestamp, platform/kernel, receiving interface, XDP mode, loader command, detector/window semantics, traffic-generator command/version, firewall state, reset confirmation, CPU scope, and timing definitions.
